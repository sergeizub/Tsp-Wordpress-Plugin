Plugin for Dance Studio Manager.

== Description ==
Dance Studio Manager plugin is a solution to connect your wordpress website with DSM clients area.

== Installation ==
Download and activate plugin.

At Admin -> Settings -> Dsm Settings input DSM Url of your current client area.
For Example: https://clients.dancestudiomanager.com/[path_to_studio]/
Then type Admin Username and Password from your DSM account.

Add shortcode [dsm_client] at the post or page where the client area should appear.
