Plugin for Travel Sports Pro.

== Description ==
Travel Sports Pro plugin is a solution to connect your wordpress website with TSP clients area.

== Installation ==
Download and activate plugin.

At Admin -> Settings -> TSP Settings input TSP Url of your current client area.
For Example: https://clients.travelsportspro.com/[path_to_studio]/
Then type Admin Username and Password from your TSP account.

Add shortcode [tsp_client] at the post or page where the client area should appear.
